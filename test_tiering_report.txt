Package 42: Pytest Test Tiering
Date: 2026-06-29

Scope
-----
Established pytest marker tiers for ZERO tests without changing runtime logic,
test assertions, or test behavior. Changes are limited to pytest marker
definitions, module-level pytestmark metadata in tests, and this report.

Markers Added
-------------
- smoke: daily fastest release smoke tests
- contract: mainline contract, seal, authority, registry, and API-boundary tests
- integration: multi-module, CLI/subprocess, workspace scan, git repo, or runtime session tests
- external: localhost, network, service, HTTP/API, or Ollama-facing tests
- llm: LLM/Ollama/model/generate/chat semantic tests
- slow: long-running, full workflow, portfolio cycle, or engineering end-to-end tests

Selection Guidance
------------------
Smoke:
  python -m pytest -m smoke -q
  python tools/regression_runner.py smoke

Contract:
  python -m pytest -m "contract and not slow and not integration and not external and not llm" -q
  python tools/regression_runner.py contract

Fast local:
  python -m pytest tests -q -m "not integration and not external and not llm and not slow"
  python tools/regression_runner.py fast

Integration:
  python -m pytest -m integration -q
  python tools/regression_runner.py integration

LLM/External:
  python -m pytest -m "llm or external" -q
  python tools/regression_runner.py llm --confirm-external

Nightly:
  python -m pytest tests -q
  python tools/regression_runner.py nightly --confirm-nightly

Runner Dry Runs
---------------
The standard entry point supports --dry-run for every tier:
  python tools/regression_runner.py smoke --dry-run
  python tools/regression_runner.py contract --dry-run
  python tools/regression_runner.py fast --dry-run
  python tools/regression_runner.py integration --dry-run
  python tools/regression_runner.py llm --dry-run
  python tools/regression_runner.py nightly --dry-run

Guardrails:
- nightly refuses to execute unless --confirm-nightly is passed.
- llm refuses to execute unless --confirm-external is passed.
- dry-run prints the command without requiring confirmation or running pytest.

Validation Notes
----------------
Do not use the Nightly command for daily smoke/contract work. It intentionally
includes subprocess-heavy, workspace-scan-heavy, slow, external, and LLM-tagged
tests.

The targeted verification command that includes
tests/test_engineering_portfolio_goal_flow.py took nearly two minutes on this
machine, supporting its slow + integration classification.
