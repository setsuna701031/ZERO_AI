Package 44: Contract Tier Refinement (Fast/Heavy)
Date: 2026-06-30

Scope
-----
Refined pytest contract tiers without changing runtime logic, production code,
test assertions, or test behavior. Changes are limited to pytest marker
definitions, module-level pytestmark metadata in tests, the regression runner,
and this report.

Markers Added
-------------
- contract_fast: fast helper/runtime/authority/parser/payload/state/registry contract tests
- contract_heavy: heavyweight contract tests involving inventory, scans,
  traversal, subprocess, CLI, or broad repository inspection

Markers Preserved
-----------------
- smoke
- contract
- integration
- external
- llm
- slow

Contract Fast Scope
-------------------
contract_fast covers helper contracts, runtime_contracts, authority helpers,
scheduler helpers, parser helpers, planner helpers, canonicalization, payload
contracts, serialization, state transitions, registry helpers, and pure
monkeypatch contracts.

Contract Heavy Scope
--------------------
contract_heavy covers contract tests with workspace or repository scanning,
inventory assertions, subprocess or CLI startup, broad filesystem traversal,
large temporary workspaces, repository inspection, engineering inventory,
runtime inventory, bridge inventory, compatibility inventory, freeze inventory,
migration inventory, or audit inventory.

Selection Guidance
------------------
Smoke:
  python -m pytest -m smoke -q
  python tools/regression_runner.py smoke

Contract Fast:
  python -m pytest -m contract_fast -q
  python tools/regression_runner.py contract-fast
  python tools/regression_runner.py contract

Contract Heavy:
  python -m pytest -m contract_heavy -q
  python tools/regression_runner.py contract-heavy

Fast local:
  python -m pytest tests -q -m "not integration and not external and not llm and not slow and not contract_heavy"
  python tools/regression_runner.py fast

Integration:
  python -m pytest -m integration -q
  python tools/regression_runner.py integration

LLM/External:
  python -m pytest -m "llm or external" -q
  python tools/regression_runner.py llm --confirm-external

Nightly:
  python -m pytest tests -q
  python tools/regression_runner.py nightly --confirm-nightly

Runner Dry Runs
---------------
The standard entry point supports --dry-run for every tier:
  python tools/regression_runner.py smoke --dry-run
  python tools/regression_runner.py contract --dry-run
  python tools/regression_runner.py contract-fast --dry-run
  python tools/regression_runner.py contract-heavy --dry-run
  python tools/regression_runner.py fast --dry-run
  python tools/regression_runner.py integration --dry-run
  python tools/regression_runner.py llm --dry-run
  python tools/regression_runner.py nightly --dry-run

Guardrails:
- contract now aliases the fast contract tier and runs -m "contract_fast".
- fast excludes contract_heavy in addition to integration, external, llm, and slow.
- nightly refuses to execute unless --confirm-nightly is passed.
- llm refuses to execute unless --confirm-external is passed.
- dry-run prints the command without requiring confirmation or running pytest.

Validation Plan
---------------
Short validation only:
  python tools/regression_runner.py contract-fast --dry-run
  python tools/regression_runner.py contract-heavy --dry-run
  python tools/regression_runner.py fast --dry-run

Do not run contract-heavy, fast, nightly, or pytest tests -q as part of this
package.

Non-mainline Issues
-------------------
- Several heavy contract files still contain repository traversal, inventory,
  subprocess, CLI, or broad scan behavior. Package 44 isolates these tests from
  fast lanes but intentionally does not optimize or rewrite them.
- Some contract files also carry integration, external, or llm markers. They
  remain excluded from fast contract by contract_heavy classification.
- Git reports LF-to-CRLF working-copy warnings for many touched test files on
  this Windows checkout; content diffs are limited to pytestmark changes.
